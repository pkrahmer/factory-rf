# The run logs

The human's logs of the factory's runs, one folder per run with its log, its plan and its reports. No [stage](../project-guide/glossary.md) reads or writes them, and [the project guide](../project-guide/README.md) is where the code is explained.

- `2026-10-12-overnight/` The first nights, when v1 built v1.1.
- `2026-10-19-baseline-todo/` The baseline todo run, its report and the instance's records.
- `2026-11-04-f0050/` The run of F0050, the factory shows what it runs and what it uses.
- `2026-11-05-f0052/` The run of F0052 to F0055, the documents and the folder READMEs.
