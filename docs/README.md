# The documents

The documents of kumpel-factory: the guide for operators, the guide for agents and developers, the decision log and the human's playbook. [The project guide](project-guide/README.md) says which file explains which area.

- `operator-guide/` The operator's guide: install, configure, the stops and what to do about each, one file per topic; start at [its index](operator-guide/README.md).
- `project-guide/` The guide for agents and developers who change the code, an index and one file per area.
- `runs/` The human's records of finished runs and sweeps; no stage reads or writes them.

Beside them, [decisions.md](decisions.md) holds the lasting decisions and what was rejected, and [operator-playbook.md](operator-playbook.md) is the human's playbook for running the factory without the human.
