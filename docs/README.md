# The documents

The documents of kumpel-factory: the guide for operators, the guide for agents and developers, the decision log and the human's playbook. [The project guide](project-guide/README.md) says which file explains which area.

- `operator-guide/` The operator's guide: install, configure, the [stops](project-guide/glossary.md) and what to do about each, one file per topic; start at [its index](operator-guide/README.md).
- `project-guide/` The guide for agents and developers who change the code, an index and one file per area.
- `runs/` The human's logs and reports of finished runs; no [stage](project-guide/glossary.md) writes them.

[decisions.md](decisions.md) holds the lasting decisions and what was rejected.
[operator-playbook.md](operator-playbook.md) is the playbook for the human who runs the factory, or a session acting for them.
