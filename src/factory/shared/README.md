# The shared area

What every other area uses: errors, times, identifiers, paths, settings, the records contract and the document check. [The guide page](../../../docs/project-guide/shared.md) explains it.

- `adapters/` Atomic files, the clock, printed output, the one module that starts processes and the validation faults.
- `application/` The ports for files and the examples of the document check.
- `domain/` The pure rules every area uses: errors, identifiers, paths, sections, settings, the contract and the document checks.
