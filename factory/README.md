# The human's factory files

The human's files that steer this factory: the pipeline definition, the forms of a story and a feature, the stops and the features. [The operator guide](../docs/operator-guide/README.md) explains them, and [the glossary](../docs/project-guide/glossary.md) names each word.

- `archive/` The finished features with their stories, acceptances and cost records, moved here once a feature is done.
- `features/` The features in work, each with its stories by state; see [its README](features/README.md).
