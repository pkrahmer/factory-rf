# planning/

The human's working files: the overnight plans, the drafts of features not yet built (`overnight/stories/`), their pre-checks (`overnight/precheck/`), the mutation sweep brief and reports, the stack-template designs and the lessons for the skills. No stage reads or writes this folder.

The history (the first nights' plans, the drafts and pre-checks of the built features, the finished briefs, the probes, v1's texts and `factory/v1/`) was removed on 2026-10-19 and is kept at the tag `planning-history-2026-10-19`: `git show planning-history-2026-10-19:<path>`.
