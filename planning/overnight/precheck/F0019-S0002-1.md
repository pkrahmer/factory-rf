## Checked against the built code and tests

- **The order of the steps.**
  - The ABI comes before the folders, so a kernel without Landlock leaves nothing behind (criterion 9).
  - The temporary folder is made with `os.mkdir(path, 0o700)`. That refuses an existing folder and an existing symbolic link (even a dangling one) with `FileExistsError` / `File exists` (criterion 10). The mode is exact under the `Makefile`'s umask 022 and the container's umask 002.
  - `restrict_writes([*folders, temporary_directory], files)` then gives the folder rules first.
- **Step 3's refused side.** `Path("…/f/sub").mkdir(parents=True, exist_ok=True)` with `f` a file raises `NotADirectoryError` (`strerror` `Not a directory`). Path.mkdir catches only `FileNotFoundError` for parents, so it does not create them. That is the row E2 adds.
- **`replace_process([])`.** `os.execvpe(argv[0], …)` with an empty list would raise `IndexError` before `execvpe`, so the coder must check and raise `ValueError` itself. Criterion 2 pins it, so this is no stop.
- **`replace_process(["no-such-program"], {"PATH": str(tmp_path)})` in-process.** `execvpe` tries `tmp_path/no-such-program`, gets `ENOENT` and raises `FileNotFoundError`. The process is not replaced, so the worker is safe.
- **ruff on `main`.** The usage line plus six steps, each returning 1, makes seven `return`s, above ruff's `PLR0911` (6). The coder will have to fold the faults (for example, one private exception caught once). It is the coder's design, not a stop. `max-args` is fine (3).
- **Structural tests after the change** (the tester, under decision 7):

## Smoke test against today's code

- None of the blocks can run before the story: `uv run factory-confine` fails with "Failed to spawn: `factory-confine`".
- **Block 1 is wrong as drafted.** `{ echo b > "$1/other/b.txt"; } 2>/dev/null || echo "other refused"` opens `/dev/null` for writing inside the restricted shell. The rules allow only `allowed/` and the temporary folder, so that open is refused.
  - dash then prints `sh: 3: cannot create /dev/null: Permission denied` on standard error and never runs the inner `echo`.
  - `other refused` is printed because `/dev/null` was refused, not `other/b.txt`.
  - The smoke tester sees a fourth line on standard error against "three lines". E1 checks the real refusal without `/dev/null`.
- Block 2: `["--", "true"]` gives the usage line. `uv run` passes on exit status 1, so `status 1` prints. **Met** after the story.
