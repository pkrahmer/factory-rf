### Code facts

Each was checked against `src/factory/adapters/opencode_runtime.py` and `agent_launch.py`.

- `parse_result_block`: the entry is `"\n".join(block[2:]).strip()`; the second line must be `entry:`. Both hold as the story says.
  - The first-line test is `startswith("decision:")` (`_DECISION_LABEL`), with **no space**. The Interface says `decision: ` (finding 3a).
- `_model_ms` resets `tools` at each `step_start` and adds every `tool_use` span. So a `tool_use` before the first step adds nothing, as the story says.
- `_denials` skips a non-denial error with `continue`. The denial test is `DENIAL_PATTERN = permission|denied`, any case. The Interface says "names a permission or a denial", which is not the same: an error saying "denial" matches neither word (finding 3b).
- `_opencode_argv` is `[*login_argv(...), executable, "run", "--format", "json", "--auto", "--model", m, "--agent", "factory-<name>", ("--session", id), prompt]`.
  - Without an API login file there are no login words.
  - The stand-in records `sys.argv[1:]`, that is, everything after the executable.
  - So "the call's words, after the login words" starts with the executable, not with `run` (finding 4).
- `_call`: `killed_at_limit` with `os_user`, a status in `KILL_STATUSES` and a duration at or past the limit marks the call `timed_out`.
  - `_result` keeps the session (`_session`) and `login_used(stderr)` on a timeout.
  - `_remove_temporary_folder` runs after every call when a confine executable is set, through `sudo` for an `os_user`.
- **The stand-in's session is fixed.** `tests/adapters/opencode_stand_in.py` builders write the session `ses_a` (`SESSION`) into every event and take no session parameter. `MODELS` maps `sonnet` to `anthropic/claude-sonnet-5-5`. `opencode_request` builds the agent `coder` with budget 1. `stand_in_runtime` makes `state`.
  - Criteria 4 and 5 name sessions `ses_s` and `ses_k`, which no builder can produce (finding 2).
- **The stand-in confine never makes the folder.** `tests/confine_support.py`'s `write_confine` only records its call and `exec`s what follows `--`. It is the real `factory-confine` (`CONFINE`) that makes the run's temporary folder.
