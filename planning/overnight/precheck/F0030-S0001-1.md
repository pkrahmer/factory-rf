- **Why criterion 5 tests nothing, measured** (20 runs each; a child starts the grandchild, writes its pid, prints `started`; the parent reads `started` and compares groups at once):
  - Grandchild calls `os.setpgid(0, 0)` itself, as drafted: it is still in the child's group at `started` in **20 of 20** runs. Its Python has not started yet, so the stop's group kill reaches it.
  - Child starts it with `subprocess.Popen(..., process_group=0)`: still in the child's group in **0 of 20** runs. Python 3.11+ sets the group in the fork, before `Popen` returns.
