   - (a) Keep the Interface and change the row: a missing program is a result with exit status 127, and the `ContainerError` is tested through a mapped working directory that does not exist (edit 1). **Recommended**: the fake stays one shell wrapper for `launch` and `run`, as S0003 (podman runs) has one command line for both.
