## Points for the human

1. **The host-side `podman` process runs with an empty environment.** `launch` returns `env={}` "as `sudo` does today, so no variable of the factory reaches the container but through `--env`". Under `sudo`, `env -i` cleared the environment of the agent's process; podman passes none of its own environment into the container anyway (only `--env` and the image's `ENV`; the proxy variables of `--http-proxy`, on by default, are the exception). So `{}` protects nothing inside the container and starves the `podman` program itself: rootless podman reads `HOME`, `XDG_RUNTIME_DIR`, `DBUS_SESSION_BUS_ADDRESS`, `PATH`, `TMPDIR` and `CONTAINERS_CONF` from its environment, and the plan (step 5 of the cycle) drops `env -i` from the chain. Podman has fallbacks (the passwd entry for `HOME`, `/run/user/<uid>` for the runtime directory, the default path for its helpers, cgroupfs when it finds no user bus, with warnings), so the drafted way will probably run on the VM, but it will tell the operator about it only in F0043's story 4, and whatever the service's environment file sets for `podman` is never seen. `version()` and `image_exists()` already run with the factory's environment (`env` `None`), so the story is inconsistent with itself.
   - A: keep `{}` as drafted; F0043's story 4 measures. No edit.
   - B (recommended): the `podman` process inherits the factory's environment. `ContainerLaunch.env` of S0001 becomes `dict[str, str] | None` (`None` is the process's own environment, as `ProcessRequest.env` says), `FakeContainerRuns` keeps returning its mapped dict, `PodmanRuns.launch` returns `None`, and `agent_launch.Launch.env` becomes `dict[str, str] | None` in S0008 (which changes that module anyway). The container's environment stays `--env` only. Edit 10 is this story's part; S0001 changes one line of its Interface code block and S0008 one line of `Launch`.
2. **S0001's `Mount` docstring** is 104 characters; ruff's `E501` (100) will make the coder shorten it. Not a stop; a line to fix in S0001's Interface before it starts.
