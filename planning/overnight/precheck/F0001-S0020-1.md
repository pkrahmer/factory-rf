- **Beyond the draft: a glob is still read as a refspec.** `push("refs/heads/x*")` pushes every local branch matching `x*` and returns `"pushed"`. `push("x*")` pushes nothing and returns `"pushed"` (git exits 0). `check_branch_name` as drafted accepts both, so the title "a pushed branch is never read as a refspec" stays false at this edge. Neither case forces or deletes. Git never allows `*` in a branch name (`check-ref-format --branch x*` fails), so refusing it would lose nothing. Refusing it would widen the human's choice (a), so it is the human's call: recommended edit 3, not a predicted stop.

### Fix 1 (the refusal): the Interface bullet and a new criterion

In `## Interface`, replace the bullet

```
- No other operation changes.
```

with

```
- The local operations keep `check_git_argument` and do not call `check_branch_name`, because git reads no refspec there: `delete_branch("+x")` and `delete_branch("x:y")` are not refused, and change nothing when no such branch exists.
```

In `## Acceptance criteria`, insert after criterion 7 and renumber the closing two to 9 (`make check`) and 10 (`docs:`):

```
8. `delete_branch("+x")` and `delete_branch("x:y")` return without error and leave the local branches as they were: the local operations keep `check_git_argument`.
```
