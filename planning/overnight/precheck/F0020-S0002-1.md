## Checked against the built code and tests

- **The behaviour does not change.**
  - `launch` repeats today's words exactly: `sudo -n -u <user> --`, then `timeout --signal=KILL <ceil>s`, then `env -i NAME=value ...`, then the argument words; the time limit gains `SUDO_GRACE`.
  - `resumed_result` now sums `duration`. Today it keeps the second call's (`_ZERO`). `run` overwrites the duration with the whole run's clock straight afterwards, so the Claude Code runtime's results do not change.
  - With `time_limit`, today's private function keeps the second call's measures and the joined denials. That is the Interface's rule.
- **Values set on the module.** The Interface requires that `claude_runtime` pass its own globals (`DEVICE_FOLDERS`, `DEVICE_FILES`, `SHELL_EXECUTABLE`, `CLEANUP_TIME_LIMIT`, `run_process`) to the shared functions at call time.
  - `tests/adapters/test_claude_runtime_confinement.py::test_the_rules_hold_only_the_device_targets_that_exist` and `test_a_removal_that_outlasts_its_time_limit_is_ended_and_changes_no_result` pin this.
  - A coder who calls `existing_devices()` with defaults bound at import time turns them red. The Interface rules this out.
- **Re-exports (E1, required).** The re-exports must go through `__all__`, as in S0001's E1.
  - `ENTRY_DESCRIPTION`, `SUDO_EXECUTABLE` and the others are used inside the module, so ruff's `F401` does not fire.
  - Without export, mypy still reports `attr-defined` for the tests' imports.
- **Source search (E2, recommended).** `tests/test_agent_run_request_search.py` names `factory.adapters.claude_runtime` alone, and changing it would need a leave. A new test module avoids that.
  - The new test is a source search, but mutmut's rewrite adds no `os.environ`, so it needs no `[tool.mutmut]` deselect.
- **Coverage.** Every moved function is covered by its new unit test and by the earlier tests of the runtime.
- **Size.** About 120 lines moved and 40 new. A small story.
