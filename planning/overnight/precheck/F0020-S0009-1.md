## Checked against the built code and tests

- **`wait_to_fit`, criterion 1's rows.**
  - 3.00 at 12:10 is not below 3, so the 12:02 record leaving gives 2 minutes.
  - 3.20 drops to 3.00 when the first record leaves, which is still not below 3; the 12:05 record leaving gives 5 minutes.
  - These are consistent with the rule.
- **Not counted:**
  - The preflight's probe (about $0.10), which runs outside `PatientRuns`.
  - The cost of a call the factory cut short (`None`).
  - The gateway limits each model on its own, while this window sums every model. That is conservative and right.
- **The spend file.**
  - It grows by one line per call and is never pruned. That is a few kilobytes a day, the same as the command records.
  - It sits on the `state` volume, so a restart keeps it.
- **Size.** About 80 lines and 10 criteria: a small story.
