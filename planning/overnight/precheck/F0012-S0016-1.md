- **What `used_bytes` of `/tmp` can see.**

  - So the `/tmp` record misses the agent's leftovers, the 8.4 GB kind the plan names.
  - The free space of `/tmp`'s file system (the container's `df`) still shows them. The record is honest only if the docs say so.
  - S0009 is outside this range. Its Interface and a criterion should state that unreadable folders are skipped.
