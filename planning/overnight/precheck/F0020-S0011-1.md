### Two facts the story's bullet for *Update the pins* misses

- `image/Dockerfile` line 66 also sets `ENV FACTORY_OPENCODE_MODELS=opus=…,sonnet=…,haiku=…`. `tests/test_opencode_image.py` requires the compose default to equal it.
- `tests/test_opencode_image.py` line 23 pins the version literally: `assert pins == ["ARG OPENCODE_VERSION=1.19.3"]`. Its `MODELS` constant pins the ids. So an opencode pin update breaks that test unless it changes too. The Claude Code pin has no such literal in a test. *Update the pins* tells the operator to run only `uv run pytest tests/test_image.py`.

### One more passage that names a Claude-only fact

*The kernel refuses every other write* names the rules file `/state/runs/confine-<session>.json` and the folder `/tmp/factory-run-<session>`.
- Under Claude Code the session id is the run's name (`claude_runtime.py` lines 156-157).
- Under opencode the runtime names both by its own `uuid4` (`_RunFiles.of(…, str(uuid.uuid4()))`), not by the session.
- The story's "No other passage changes" would keep the documenter from fixing it.
