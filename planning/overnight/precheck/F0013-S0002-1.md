## Facts checked

- **No existing test breaks.** Every test that hands the preflight a token file puts it directly in `tmp_path` (mode `0700`, the test's own uid); `test_agent_user_item.py` uses only `exists`. Only `test_token_file_item.py` changes, by the leave.
- **Write paths.** `src/*` and `tests/*`; documents in `docs/*`.
- **The order of the rule has no criterion** (stage-intake step 3, "an ordering"). The Interface says "checked in this order, the first fault found being the detail", but every failing row has exactly one fault, so any order passes. Two coders, two orders.
- **The order the Interface chose has a hole.** It stats the file before the folder. When the folder belongs to another user and lacks `x` for others (the case the new owner fault is for, with mode `0700`), `stat(path)` raises `PermissionError`, not `FileNotFoundError`. The item does not catch it. `Preflight.run` builds the extras with no `try`, so the tick ends in an exception instead of a `preflight_failed` stop naming the folder. If the folder is checked first, that cannot happen. A missing folder then raises `FileNotFoundError` on the folder, which is still "the token file does not exist". The likely real case (an image without the folder, where the runtime makes the mount point's parent as root `0755`) is reported either way.
- **The mask, bit by bit.** Criterion 1's failing modes `0750`, `0710`, `0705` and `0701` never set a write bit and never set a read bit alone. A mask of `0o011` or `0o055` passes them all. `CLAUDE.md` asks for each limit on both sides; the six bits of `0o077` are the limit. Rows `0740`, `0720`, `0710`, `0704`, `0702` and `0701` test one bit each.
- **Criterion 5's "exactly those two paths"** is a set or a sequence depending on the reader; with the order fixed it should say which path first and how often.
- **Mode in the detail.** `f"{mode:04o}"` gives `0750`, as the Interface says.
- **Checks.** No new marker; `os.stat_result` from a tuple is already used by the current test; nothing for semgrep or bandit.
- **Size.** One function and one test module. Well inside $2 and $4 and one lease.

### Edit 1: Interface, the rule

Replace the table and the paragraph after it with:

```markdown
| Case | Fault |
|---|---|
| `path` is `None` | `no token file is set` (as now) |
| `stat(path.parent)` raises `FileNotFoundError` | `the token file does not exist` |
| `stat(path.parent).st_uid != uid` | `the folder <folder> belongs to uid <n>, not to <uid>` |

The item reads only through `stat`: once with `path.parent`, then, only when the folder passes, once with `path`, and with nothing else; the token file's own owner and mode do not count. `_GROUP_AND_OTHERS` keeps its value; the faults on the file's owner and mode are removed. ```
