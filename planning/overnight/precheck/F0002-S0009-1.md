- **The alternative implementation the criteria do not exclude.** A `NewEntry` validator that appends the closing run to the text, skipping the first line, makes c1 to c7 pass as well, because `render_entry` then indents a text that is already closed. Only the Interface's rule "`NewEntry.text` and the journal record are unchanged" forbids it, and it has no criterion.
