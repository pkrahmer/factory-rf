**A link above a kept path is followed (prototype written to the letter of the Interface).** In a home whose `.config` is an owned link to a folder outside the home, with `--keep .config/sso`, the program exited 0. **It emptied the folder outside the home (`work.py` gone) and left the link.** The rule reads: "`descend` when a kept path lies beneath `relative` ..., or when `folder` is true". That gives `descend` for an entry that is not a folder, and walking a link follows it. That contradicts "No link is followed". `.local` always has a kept path beneath it (`.local/share/opencode/auth.json`, S0004), so a run that replaces `~/.local` with a link to `/work/checkout` would make the next reset remove `agent`'s files in the checkout before the checks run. Edit 2: only a real folder is walked.
