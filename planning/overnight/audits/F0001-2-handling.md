Criterion wording below is shortened where long; "old → new" shows what changed.

Two departures from the round 2 answer's literal text, both to keep `make check` green:

- The constructor reads `GitCli(directory, options: GitOptions | None = None)` and makes `GitOptions()` inside. The answer's `options: GitOptions = GitOptions()` is a call in a default value, which ruff's `B008` (selected: `B`) rejects, and no `noqa` is allowed (S0004 c14). `GitCli(work)` and `GitCli(work, GitOptions(...))` work as the answer says.
- `GIT_TIME_LIMIT` moves to `factory.domain.git`, because `GitOptions` (in the domain) needs it as a default and the domain may not import an adapter.
