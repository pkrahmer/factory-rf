# The code says what it does, once

## Goal

The read-only review `planning/overnight/mess-scan-2026-10-20.md` found code that says something other than what it does, and code written twice. A docstring of `Tick` (`src/factory/application/tick.py`) says "nothing local is read", though every tick reads the instance's health file and its stop records and publishes them; its `run` docstring leaves the publication out. `CheckoutPreparer.prepare` (`src/factory/application/scheduler.py`) is typed `-> bool` and documented "always `True`", and its one caller ignores the value: a reader looks for a `False` that does not exist. The two agent runtimes (`claude_runtime.py`, `opencode_runtime.py`) each read the end of a call in the same lines, with the same comment: the kill by the runtime's own `timeout` and then the refusals of `sudo`, the write guard's wrapper and the login shell, and each writes the state-directory error text itself; a fix to that fault path in one runtime only is the likely next bug, and F0029 and F0030 keep working on it. Twenty-nine test modules hold copies of shared helpers: sixteen copy the `definition` fixture as `_definition`, five copy `log_support.log_lines`, five copy `stage_run_support.pushed_state` or its reading, and others copy fixtures of `tests/conftest.py` or of each other; the guard `tests/test_shared_fixtures.py` matches only the fixture's own spelling and misses all of them. `NOT_YET_HANDLED` (`src/factory/entry/wiring.py`) has been `()` since every event kind got its handler, and five tests compare it with an empty set under names that claim more. This feature fixes each at its cause: the shared reading moves into `factory.adapters.agent_launch`, the test copies give way to one shared place each with a guard that finds them by their body, the docstrings and the return type say what the code does, and the empty constant goes. It is for the agents, who read docstrings and test helpers as the design, and for the human, who reviews one copy instead of five. Each finding was checked against the code of 2026-10-20 before it was drafted. Done when every story below is merged and `make check` is green.

## Decisions taken for the human

1. **The cause of the runtimes' copy.** F0020 moved the words, rules, refusal readers and the resume share into `agent_launch` (the decision log's *What the agent runtimes share lies in one module*), but the sequence that uses them at the end of a call stayed in each runtime's `_call`, with the same comment twice: read the own `timeout`'s kill as the time limit first, then read the refusals with that reading.
