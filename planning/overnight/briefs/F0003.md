## The format v1 requires (code checks the first two, intake the third)

- `FEATURE.md`: `# <title>`; `## Goal` (a paragraph with a "Done when" sentence); `## Scope` and `## Out of scope` (bullets); `## Stories` with lines `- S0001 — <title>` matching the drafts; `## Decisions taken for the human`, with an item for every product decision you took in writing the stories, each naming its story ("(S0002, story text)").
- A story: file stem `F0003-S000M-<slug>` (lowercase letters, digits, hyphens); no front matter; exactly one line starting `# ` (the title); every `## ` section of `factory/TICKET.md` in its order: `## Assignment (as of log entry 1)`, `## Interface`, `## Acceptance criteria`, `## Demo`, `## Log (append only)`.
- Assignment: a paragraph saying what is built and why, naming the condition ids it covers (for example "covers GH1.1, GH1.3; keeps kept thing 13").
- Interface: concrete module paths, class and function names, exact signatures, error types, as code blocks per file, then the rules as bullets, then a "Tests:" line naming the test modules. Every behaviour stated in an Interface comment has a criterion.
- Acceptance criteria: numbered 1 to n, one behaviour each, each testable by one test function without further decisions; every rule gets a criterion for its failing side; every limit is stated with its number, and both sides are tested; the second-to-last is exactly `make check stays green.`; the last starts with `docs:` and names the documents it touches among `README.md`, `docs/operator-guide.md`, `docs/project-guide.md`, `docs/decisions.md` (WE6.3), or says `none` with the reason. At most 26 criteria; aim for 8 to 18.
- Demo: one or more fenced blocks, each a command run from the repository root in v1's container (Linux, nothing listening, no network, no files beyond what it creates, typically `uv run python -c "…"`), each followed by a line starting `Expect:` that states output the command can be checked against.
- No line inside any code fence starts with `# ` or `## ` (the heading scan ignores fences): write Python comments as `#comment` only after code on the same line, or indent them.
- Log: exactly `1. 2026-10-12 human: created.`
- No clock time anywhere except that date.

## What makes a story pass v1 (avoid each)

- Intake asks when: the Interface is not concrete; an Interface comment's behaviour has no criterion; a rule has no failing-side criterion; a limit lacks its number; a Demo is not runnable or an `Expect:` is not checkable; the story is outside `FEATURE.md`'s Scope or against `CLAUDE.md`'s architecture.
- The coder asks (and the story stops) on a new dependency, a new top-level package, a change to `factory/`, a write outside its write paths (`src/*`, `image/*`, `template/*`, `claude/*`), or a test contradicting the Interface. Use only the dependencies in `pyproject.toml` and the standard library.
- Container limits: no Docker, root, second OS user, network or real GitHub inside v1's container. Where a condition needs one (parts of ST3.3, ST5.1, WE3.1, WE3.3), write a static test of the files instead and name the rest "morning observation" in the Assignment.
- Size: one story must fit the coder's $4 budget with one resume and a 60-minute lease. Split rather than exceed 26 criteria.
- Nothing writes a file named `FEATURE.md` except the human: if v1.1's own template needs a feature form, name it `FEATURE-FORM.md` or say in the Assignment that the human adds it.
- Tests use a real local bare git remote in `tmp_path` for git, and the one fake for the hosting service; the agent runtime is faked through its interface.

## From conditions to criteria

- Each acceptance condition your feature carries becomes one or more criteria of the story that builds its mechanism, split until each is one behaviour, with the failing side and both sides of each limit added.
- A condition phrased as an inspection or a search becomes a test that searches the code (for example: "no module outside `factory.adapters.github` imports `github`").
- A story never builds v1's old mechanism only for a later story to replace it.
